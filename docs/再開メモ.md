# 作業再開メモ（自分用）

PC を落としても、コードも会話履歴もディスクに残るので消えません。
明日以降はこの手順で再開できます。

## 1. Claude Code を再開する

ターミナルで、このプロジェクトのフォルダに移動してから起動します。

```sh
cd ~/works/dmu-p4-cheat-sheet
claude --continue
```

- `claude --continue`（短縮 `claude -c`）… 直近の会話をそのまま再開。今までのやり取り・経緯を引き継ぐ。**基本これでOK。**
- `claude --resume`（短縮 `claude -r`）… 過去のセッション一覧から選んで再開したいとき。
- ただ `claude` だけ … まっさらな新規セッション（前回の会話は引き継がない。※記憶ファイルの要点だけは自動で読まれる）。

## 2. アプリを動かして確認する

```sh
npm run dev
```

- 起動したら表示される `http://localhost:5173/` をブラウザで開く（WSL なので Windows 側ブラウザからでもOK）。
- ファイルを編集すると自動で反映（ホットリロード）。
- 止めるときは `Ctrl + C`。

ビルド（本番用の出力を作る／型チェック）は:

```sh
npm run build
```
