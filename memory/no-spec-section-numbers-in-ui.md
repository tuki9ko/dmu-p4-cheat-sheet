requires.md のドット番号（1.2 / 1.3 / 2.1〜2.8 や入力の「1.2.3.4.」連番）は仕様を伝えるための便宜上のもの。**UI・マクロ出力・見出しに表示しない**。

**Why:** エンドユーザーには内部のセクション番号は無意味で、攻略中の視認性を損なう。

**How to apply:** 早/遅・種別(炎/水・ほのお/つなみ)・GC1/GC2由来・呪詛などゲーム上意味のあるラベルは残す。グランドクロスは「1回目/2回目」やGC1/GC2で表す。ドット番号やセクション連番は出さない。[[project-status]]
